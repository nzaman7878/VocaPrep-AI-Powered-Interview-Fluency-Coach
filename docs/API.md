# API Documentation

_This file will contain the REST API endpoints and schemas._

## Authentication

- `POST /api/auth/register`
- `POST /api/auth/login`

## Users

- `GET /api/users/me`
- `PUT /api/users/me`

## Sessions

- `POST /api/sessions`
- `GET /api/sessions/:id`

## Questions & Evaluation

- `POST /api/questions/generate`
- `POST /api/evaluate`
